Risultati

Un rapporto uguale/adattivo maggiore di 1 favorisce lo scheduler adattivo; minore di 1 favorisce le quote uguali. Nessuna conversione in potenza di dispositivi reali per le simulazioni.

Come produrre i report

Dalla cartella alpha: npm run lab:real esegue Monte Carlo con 10 e 50 nodi locali; npm run lab:scale simula 100 e 1.000 nodi; npm run lab:multi verifica più richieste concorrenti. Trovi i file nella cartella results.
